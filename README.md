# 진저브레드맨 영어 모의고사 ☁️

고전 읽기 *The Gingerbread Man* 이야기의 단어와 문장으로 만든 영어 모의고사입니다. 깔끔한 디자인에 은은한 파스텔 포인트, 찹쌀떡 친구 말랑이가 함께해요.

- 1~6회 고정 모의고사 + 랜덤 시험지 (회당 33문제: 단어 쓰기 15, 동사 찾고 해석 5, 문장 배열 5, 우리말 영작 5, 질문에 영어로 답하기 3)
- 1~3회와 4~6회는 서로 다른 문장으로 출제
- 자동 채점, 영역별 점수, 점수에 따라 바뀌는 말랑이 표정
- 틀린 단어·문장 복습 퀴즈, 단어장(49단어, 발음 듣기)

`index.html` 하나로 동작하는 정적 사이트입니다.
